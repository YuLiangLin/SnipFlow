# Third-party components

- **Avalonia 12.1.3**: cross-platform user interface (Windows and Linux), including Avalonia.Desktop, Avalonia.Themes.Fluent, Avalonia.X11, Avalonia.Win32 and Avalonia.FreeDesktop. Copyright AvaloniaUI OÜ. [Source and license](https://github.com/AvaloniaUI/Avalonia). MIT license text: `licenses/Avalonia-MIT.txt`.
- **SkiaSharp and HarfBuzzSharp** (used by Avalonia for rendering and text shaping): Copyright Xamarin, Inc. and Microsoft Corporation. [Source and license](https://github.com/mono/SkiaSharp). MIT license text: `licenses/SkiaSharp-MIT.txt`.
- **AvaloniaEdit 12.0.0**: local code editing and syntax highlighting for code images. Copyright Eli Arbel and AvaloniaEdit contributors; derived from AvalonEdit (Copyright AvalonEdit Contributors). [Source and license](https://github.com/AvaloniaUI/AvaloniaEdit). MIT license texts: `licenses/AvaloniaEdit-MIT.txt`, `licenses/AvalonEdit-MIT.txt`. Code images use the built-in highlighting definitions; no external syntax files are loaded.
- **Tmds.DBus.Protocol 0.94.1**: D-Bus client for xdg-desktop-portal on Linux (screenshots, screen casts, global shortcuts). Copyright Tom Deseyn. [Source and license](https://github.com/tmds/Tmds.DBus), MIT license (same terms as `licenses/Avalonia-MIT.txt`).
- **Fluent UI System Icons**: application icons drawn as vector paths (`src/Ui/Icons.Data.cs`). Copyright Microsoft Corporation. [Source and license](https://github.com/microsoft/fluentui-system-icons). MIT license text: `licenses/FluentUISystemIcons-MIT.txt`.
- **Velopack 1.2.161**: installation and automatic updates (Windows installer, Linux AppImage). Copyright Velopack contributors. [Source and license](https://github.com/velopack/velopack). MIT license text: `licenses/Velopack-MIT.txt`.
- **LibVLCSharp 3.10.2** and, on Windows, **VideoLAN.LibVLC.Windows 3.0.23.1** (a reduced set of LibVLC 3.0 files: the engine, MP4 demuxing, FFmpeg-based decoding, video memory output and Windows audio output): video editor preview playback. Copyright VideoLAN and the VLC authors. [LibVLCSharp source](https://code.videolan.org/videolan/LibVLCSharp), [VLC source](https://code.videolan.org/videolan/vlc). GNU LGPL 2.1 or later: `licenses/LibVLC-LGPL-2.1.txt`. LibVLC is loaded dynamically and can be replaced. On Linux SnipFlow uses the system's libvlc instead of shipping it.
- **ScreenRecorderLib 7.0.1** (Windows only): Windows screen capture, H.264 encoding, and WASAPI audio. Copyright Sverre Skodje. [Source and license](https://github.com/sskodje/ScreenRecorderLib). MIT license text: `licenses/ScreenRecorderLib-MIT.txt`.
- Self-contained packages include the Microsoft .NET runtime and its included license notices. On Windows, recording uses Windows Media Foundation and the Microsoft Visual C++ runtime; Setup checks the Visual C++ x64 prerequisite through Velopack.
- On Linux, SnipFlow calls system programs and libraries that are installed separately and not distributed with SnipFlow: FFmpeg (recording, video export, thumbnails), Tesseract OCR, PulseAudio/PipeWire utilities, GStreamer with the PipeWire plugin, xdg-desktop-portal, libvlc and the X11 libraries.

The generated SnipFlow icon is documented in `brand-design.md`.
