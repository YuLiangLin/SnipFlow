# SnipFlow icon

## Current design: Flow S (0.4.0)

The user selected proposal A, a neutral graphite tile with a warm white flowing S. It was generated with the built-in imagegen tool using the previous logo as an edit reference. The unchanged source image is saved in `src/Assets/SnipFlow-v3-master.png`; application PNGs and the 16, 24, 32, 48, 64, 128 and 256 px ICO entries preserve the same artwork and transparency. The shell, tray and installer use this icon.

### Prompt

Use case: logo-brand. Asset type: polished Windows desktop app icon proposal A for SnipFlow, a screenshot and annotation app. Edit the supplied icon into a refined neutral graphite version fitting a Codex/ChatGPT-like desktop aesthetic. Preserve the recognizable flowing S monogram formed by two offset rounded capture corners, and its optical balance. Replace all midnight-blue, neon cyan and mint with a charcoal #252525 rounded-square tile and warm off-white #ECECEC mark. Geometry should be thick, quiet and precise with clean negative space; improve subtle corner proportions for crisp 16–32 px recognition. Extremely restrained satin depth, near-flat icon design, subtle natural edge definition only, no glow, no iridescence, no glass, no plastic bevel. One single large icon centered with generous transparent padding around the square tile, front view, square composition. No text, no letters outside the S symbol, no labels, no slogans, no border frame, no scene or mockup, no watermark. Produce a genuinely transparent background.

## Prompt

Use case: logo-brand. Asset type: production Windows app icon and logo mark for SnipFlow, a screenshot, annotation and screen recording desktop app. Create ONE polished icon, centered on a genuinely transparent square canvas, no text or letters. A deep midnight-indigo rounded-square tile, containing a bold, distinctive mint-to-cyan geometric capture-frame symbol: two offset crop corners form a flowing negative-space S with a crisp diagonal cut. The mark should communicate precise capture and flow, with restrained dimensional depth and a clean, luminous teal edge, like a carefully crafted modern Windows 11 productivity icon. Keep the silhouette simple and recognizable at 16 pixels. Strong contrast, generous optical balance, thick clean geometry, very subtle gradient and refined lighting, no thin details. Tile occupies about 85 percent of the square. Palette consistent with #151D2B, #63D5C5, cyan and near-white. No scissors, no cameras, no circular lens, no extra objects, no UI mockup, no lettering, no slogans, no watermark, no checkerboard background, no dramatic glow or long shadow.
