# SnipFlow · 快剪

Windows 截圖、標註與錄影工具，以 C# / WPF 開發。支援直接擷取程式碼長圖、本機 OCR、跟隨捲動的長對話截圖與 GitHub Releases 自動更新。

## 使用

首次取得程式可從 [GitHub Releases](https://github.com/YuLiangLin/SnipFlow/releases) 下載 `SnipFlow-win-Setup.exe`，或解壓縮 `SnipFlow-win-Portable.zip`。0.4.2 起兩者都支援程式內一鍵更新。

- `Ctrl + Alt + S`：預設全域框選截圖。焦點在瀏覽器或其他程式、SnipFlow 最小化或隱藏至系統匣時都可使用；程式須保持執行。
- 設定的「全域截圖快捷鍵」欄位可直接按下自訂組合：字母／數字搭配 Ctrl、Alt、Shift 中至少兩個鍵，或 F1–F11。輸入完整組合後立即套用並儲存；被其他程式占用時會提示並保留原有綁定。「預設」按鈕可重新註冊預設組合。
- 框選時 `Esc`／右鍵取消；支援多螢幕與跨螢幕範圍。
- 「新截圖」與小型面板旁的下拉按鈕、左側截圖圖示及系統匣提供框選、視窗、單一螢幕與全部螢幕四種模式。
- 長頁截圖使用「長截圖」按鈕：先點選視窗，再框選視窗內的對話或程式碼區；旁邊的下拉選單仍可選「框選長截圖」。程式內 `Ctrl + O` 開啟圖片。Ctrl + N／Ctrl + Shift + N 不再綁定截圖。
- 右上角「複製含標註圖片」或 `Ctrl + C`：複製包含箭頭、文字、框線等標註的合成圖片，再貼到其他程式。文字編輯期間 `Ctrl + C` 仍複製選取文字；按圖片複製按鈕會先完成文字編輯。
- `Ctrl + S`：另存 PNG；`Ctrl + V`：貼上圖片。剪貼簿只有純文字時，開啟程式碼長圖預覽；在文字輸入框內仍正常貼上文字。
- `Ctrl + Z`／`Ctrl + Y`：復原／重做；`Ctrl + Shift + Z` 也可重做。
- `V / A / R / E / P / H / T / M`：選取、箭頭、矩形、橢圓、畫筆、螢光筆、文字、馬賽克。
- 文字直接在畫布輸入；雙擊既有文字重新編輯，`Ctrl + Enter` 或點外部完成，`Esc` 取消。輸入、完成後顯示與匯出共用字型及排版設定。
- 選取後可拖移標註、拖控制點調整大小；箭頭可拖兩端。屬性列可修改選取項目的顏色、粗細或字級。
- 色彩列提供 8 個快捷色；「更多顏色」有 48 個色彩、最近使用的 8 個色彩，以及 HEX／RGB 自訂色。自訂色在按「套用」後才修改標註，可一次復原；畫筆、框線、箭頭和文字共用色盤。
- PNG 儲存與截圖歷史是合成圖片；同一次編輯期間保留可修改的標註物件，重新開啟 PNG 不含物件資料。
- 滾輪縮放；中鍵或空白鍵拖曳移動畫布。
- 啟動時顯示 420 × 264 的小型面板；開圖／截圖後展開編輯器。上方「小型面板」按鈕可縮回並保留目前的編輯內容。
- 設定可即時切換繁體中文、English、简体中文。介面語言與 Windows OCR 語言套件分開。
- 左側操作列使用純圖示；滑鼠停留時顯示功能 tooltip。最大化範圍依目前螢幕工作區調整，設定與結束按鈕保留在底部。
- 關閉主視窗後留在系統匣；使用系統匣選單或左下角的結束按鈕退出。
- 再次啟動會喚起既有視窗，同一個 Windows 工作階段只保留一個實例。

## 視窗與多螢幕截圖

「視窗截圖」將滑鼠停在目標視窗上高亮範圍，點一下擷取該視窗。「單一螢幕截圖」點選要擷取的螢幕；「全部螢幕截圖」一次擷取所有顯示器，保留 Windows 的實際排列，顯示器間沒有畫面的空隙為黑色。擷取使用實際像素座標，支援負座標和不同縮放比例的顯示器。

視窗模式使用 Windows 圖形擷取取得目標視窗本身，避免混入遮在上面的其他視窗。視窗在選取後關閉、隱藏或移動時會要求重新選取。Windows 工作階段不支援擷取或受保護內容仍有系統限制；失敗時會提示改用框選或螢幕模式。

一般截圖的選取畫面可用 `R` 框選、`W` 視窗、`S` 單一螢幕、`A` 全部螢幕切換模式。`Esc`／右鍵取消。所有截圖模式沿用標註、複製、自動儲存及合圖流程。

0.6.3 的長截圖與程式碼長截圖預設先選視窗，再框選該視窗的內容區。第二步只能在選定視窗內開始拖曳，拖出範圍時會停在內容區邊界；仍需自己避開固定側欄、標頭與輸入框。兩步都可用 `Esc`／右鍵取消，保留原本編輯中的文件。小型面板下拉選單、左側圖示右鍵及系統匣提供「框選長截圖」，可直接框選螢幕區域；錄影仍使用原有的框選流程。

捲動截圖擷取目標區域的實際可見畫面，固定使用選取時的視窗身分與位置，不會改抓同位置的其他視窗。選取後會將指定視窗移到前景；無法啟用、被遮擋或選取期間位置變動時需重新選取。開始收集後，切換程式、移動或縮放目標視窗會暫停接受新畫面，已截內容保留，可按「完成」。

## 最近截圖清理

每張歷史卡片旁的垃圾桶或右鍵選單可刪除單張紀錄；「最近截圖」標題旁的垃圾桶可清空全部，執行前會確認。清理只刪除 SnipFlow 管理的歷史 PNG 副本，目前正在編輯的圖片、合圖物件、自動儲存的圖片與另外匯出的檔案會保留。清理失敗會顯示結果並保留未刪除的紀錄。

合圖模式中，點一下最近截圖只選取縮圖；按住縮圖拖到畫布後放開才加入圖片。拖入畫布時顯示半透明預覽，依放下的位置插入；取消拖曳或放在畫布外不改動合圖。加入後仍可移動、縮放和復原。

## 登入 Windows 時啟動

到「設定 → 一般」開啟「登入時啟動」，下次登入 Windows 時會常駐系統匣，全域截圖快捷鍵仍可使用。這個選項預設關閉，不會因為安裝新版而自動開啟；切換後立即儲存。

設定頁依目前使用者的有效 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SnipFlow` 項目顯示勾選狀態。命令包含 `--background`；安裝版與正式可攜版使用更新目錄外的固定 launcher，並以檔案 handle 確認實際路徑，避免依賴啟動 host 的檔案路徑別名。找不到啟動程式或設定寫入失敗時會保留原有登錄值並在設定頁提示。

可攜版需保留完整程式資料夾；移動資料夾後，請在新位置開啟 SnipFlow，再重新開啟「登入時啟動」。更新會使用同一個 launcher 路徑。關閉此選項只移除 SnipFlow 的登入啟動項目。

## 自動儲存

0.4.1 預設啟用 PNG 自動儲存，資料夾為 Windows 的「圖片」資料夾下的 `SnipFlow`。到「設定 → 一般」可以關閉自動儲存、選擇資料夾或開啟該資料夾。

每張截圖建立自己的 PNG；完成標註或修改後約 1 秒更新同一個檔案。輸入文字、拖移或繪製途中不會中斷操作，完成操作後才存檔。切換圖片、重新截圖、結束或手動套用更新前，會先存完目前內容。寫入失敗會顯示狀態，未儲存的圖片仍可選擇手動儲存或取消離開。

關閉自動儲存時，已開始的背景儲存會先完成，再保存目前畫面，包含復原／重做後的結果。

開啟或貼上的圖片也會建立自己的自動儲存副本，原始檔案不會被覆寫。變更資料夾後，目前圖片會另存到新位置；既有檔案不會搬移或刪除。自動儲存的 PNG 不受最近截圖的 80 張保留上限影響。

「保留最近截圖」另行保存原始截圖於 `%LocalAppData%\SnipFlowData\History`，可單獨關閉。歷史與 PNG 為合成圖片；可拖移的物件另外儲存在 `.snipflow` 專案檔中。

所有設定變更會立即套用並儲存到 `%LocalAppData%\SnipFlowData\settings.json`；無須按儲存。無法套用快捷鍵或寫入設定時，會保留原來的設定並顯示原因。

## 多張合圖與物件編輯

0.5.0 加入「多張合圖」：小面板按「合圖」，或按左側合圖圖示。原本的截圖和標註會一起放入白色畫布；若尚未開啟圖片，則建立 1920 × 1080 空白畫布。

- 「加入圖片」可一次選多張；也可拖入檔案、`Ctrl + V` 貼上圖片，或將右側歷史縮圖拖到畫布。在合圖工作區再次截圖或產生程式碼長圖會直接追加圖片。
- 圖片可自由拖移，四角縮放維持比例。`Ctrl`／`Shift` 點選可多選；在空白處拖曳可框選物件。多選後可一起移動、刪除或複製。
- 「排列」提供網格、直向、橫向排列；至少選取兩張圖片時只排列所選圖片，其餘情況排列所有圖片。排列維持比例，必要時增加畫布；文字與其他標註保持原位置。
- 「對齊」提供六種對齊與水平／垂直平均分布；「圖層」調整上下順序。右鍵物件也能使用這些操作。雙擊文字直接編輯，`F2`／`Enter` 也可編輯已選文字。
- `Ctrl + A` 全選、`Ctrl + D` 複製物件、方向鍵移動 1 px、`Shift + 方向鍵` 移動 10 px、`Delete` 刪除。各次修改可復原／重做。
- 「畫布」提供 16:9、A4 直向、依內容縮合與「新合圖」。縮小畫布不會裁掉物件；物件超出新尺寸時會提示先調整。

「複製含標註圖片」／`Ctrl + C` 複製整張合圖，可直接貼到 PowerPoint、文件或聊天。「儲存 PNG」匯出合成圖片；「儲存專案」／合圖中的 `Ctrl + S` 保存 `.snipflow`，保留原圖、物件位置、文字與標註，透過「開啟圖片」／`Ctrl + O` 可繼續編輯。`Ctrl + Shift + S` 可另存可編輯專案，單張圖片也適用。

開啟自動儲存時，合圖會在設定的截圖資料夾內同時更新 PNG 和同名 `.snipflow` 副本；兩者都寫入完成才視為已儲存。自動儲存不覆寫匯入的圖片或專案。關閉自動儲存時，切換文件或結束前會提示保存可編輯專案；僅匯出 PNG 不會把尚未保存的合圖物件視為已存。

每份合圖最多 24 張圖片、原圖合計 80 百萬像素；畫布上限 40 百萬像素且各邊不超過 16384 px。專案檔只使用本機 ZIP 與 PNG，不包含執行程式碼，也不會上傳到 GitHub。

## 程式碼長截圖

0.6.3 的小型面板、左側 `</>` 圖示與系統匣「程式碼長截圖」會先選視窗，再直接擷取其中的程式碼區。無須複製或貼上程式碼，畫面中的語法顏色、字型與行號會照原樣保留。

1. 在 Visual Studio、VS Code 或其他編輯器捲到要截取的開頭，按「程式碼長截圖」。
2. 點選編輯器視窗，再框選其中會捲動的程式碼區，可包含行號；避開固定分頁、搜尋框、側欄與底部工具窗。框選後立即開始收集。
3. 自己慢慢往下捲，每次保留部分重疊。操作條會顯示已收集長圖；捲到終點後按「完成」，不必逐頁加入。
4. 如需裁切第一頁與最後一頁，可用操作條上的起點／終點選擇；不調整時直接保留框選範圍。完成後沿用標註、複製、自動儲存與合圖，取消會保留目前文件。

此流程只擷取畫面，不讀取編輯器的原始檔案或剪貼簿，不會主動捲動。切換程式、移動視窗或內容被遮擋時會保留已收集內容並暫停；接縫不可靠時需回捲恢復重疊或手動接合。大量重複程式碼、游標閃爍與編輯器動畫仍可能影響拼接；未實測各編輯器的所有情境。長截圖與聊天共用 64 張、來源合計 60 百萬像素、輸出 40 百萬像素的上限。

### 以文字製圖

原有的本機程式碼製圖仍可透過編輯器的 `Ctrl + V` 使用：剪貼簿只有純文字時，開啟預覽視窗，可選擇語言、配色、字級、圖片寬度、換行與起始行號。修改後需按「產生預覽」，再複製、儲存或加入編輯器。這個附加流程的語法配色由本機規則產生，可能與原編輯器不同；最多 100,000 個字元、2,000 行、每行 4,096 字元，圖片高度最多 16,384 px、合計 40 百萬像素。

## OCR 與長對話截圖

OCR 使用本機 `Windows.Media.Ocr` 與 Windows 已安裝的語言套件。沒有安裝對應語言時會提示；截圖與文字不會上傳到 GitHub 或其他辨識服務。

0.6.3 預設為 **選視窗 → 框選視窗內的對話區 → 捲動 → 完成**，以 LINE 桌面版與 Chrome 的 Google Chat 為主要情境：

1. 按「長截圖」，先點選 LINE 或 Chrome 視窗，再框選其中會捲動的訊息區，避開固定標頭、側欄與輸入框。
2. 框選後立即開始收集。回到對話正常捲動，每次保留部分重疊；預覽顯示已收集的內容，不必逐頁按「加入」。
3. 最後一則訊息出現在畫面後，按「完成」。成品會回到編輯器，可繼續標註、複製、儲存或加入合圖。
4. 需要精確起迄時，展開「微調範圍」，從已收集的第一張／最後一張畫面選起點和終點，不必重做整段截圖。

點選邊界時可用方向鍵微調 1 px、Shift + 方向鍵微調 10 px，Enter 確認，Esc／右鍵取消。調整邊界保留已收集畫面；較早的內容可補到前端，捲回已收集範圍不會重複追加。這是畫面位置的起迄選取，不會讀取 LINE／Google Chat 的訊息資料，也不會主動操作捲輪。

保持目標視窗大小與位置固定；小型操作條提供暫停、繼續、完成和取消，邊界與接縫操作收在進階區。切到其他程式或擷取區域被遮住時會暫停並保留內容，仍可完成已收集的部分。尚未對齊的畫面會提示處理接縫、回捲恢復重疊，或明確選擇只完成已收集內容；不會直接把低信心畫面拼進成品。

Codex、Claude 與其他可捲動視窗也可使用相同流程。「微調範圍」可指定略過頂部／底部的像素數；此裁切套用到所有已收集畫面，至少保留 48 px 高的內容，且不能排除已選起點或終點。動畫、重複段落與一次捲動太遠仍可能影響對齊；可用手動接合查看原始像素的接縫預覽。上限為 64 張、來源合計 60 百萬像素、輸出 40 百萬像素；達到上限後可完成已收集內容，或分段截取。

## 螢幕錄影

按「螢幕錄影」框選範圍，再按操作條的「開始錄影」並選擇 MP4 儲存位置。只有按下開始才會錄製；停止後完成 H.264 / 30 fps MP4。系統聲音與麥克風可獨立開關（預設系統聲音開、麥克風關），滑鼠游標可選；操作條不會出現在影片中。取消會捨棄這次的未完成影片。錄影不會取代目前的截圖標註。

影片寬高須為偶數，必要時右側／底部最多內縮 1 像素。錄影使用 Windows 圖形擷取、Media Foundation 與 WASAPI。需要可用的 GPU、Media Foundation 和 Visual C++ 2015–2022 x64 runtime；Setup 會檢查 Visual C++，Windows N 版可能需要另外安裝 Media Feature Pack。錄製受保護內容可能呈現黑畫面。

新 Logo 與多尺寸 Windows icon 的來源與生成 prompt 收在 [brand-design.md](brand-design.md)。第三方元件見 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 更新

「設定 → 更新」顯示目前版本、最新版本、檢查狀態與下載進度。檢查失敗時會在頁面內顯示原因與重試按鈕。GitHub 更新來源固定內建，不依賴程式旁的 JSON 設定檔。

安裝版與正式可攜版由 Velopack 從本專案的公開 GitHub Releases 取得套件。按「立即更新」會下載、保存目前工作、套用並重新啟動，無須開啟瀏覽器或操作安裝精靈。已背景下載完成時，按「重新啟動並更新」即可。預設在啟動時與每 4 小時檢查，找到新版後背景下載；結束程式後下次啟動也會套用。已有視窗時再次啟動會喚起工作區。離線或下載失敗不會阻止使用目前版本。設定頁可關閉自動檢查／下載。

0.6.1 在小型面板底部加入「重新啟動並更新」按鈕，下載完成就會出現；編輯器與設定頁使用相同更新流程。截圖、錄影或其他操作尚未完成時，主視窗的更新按鈕暫停使用。小型面板只在按鈕顯示時增加 16 px 高度，保留原有截圖控制的空間。

直接從 `dotnet publish` 資料夾執行 `SnipFlow.exe` 時，同一按鈕會在背景取得官方 Setup，核對 GitHub 提供的 SHA-256 與檔案大小，等待目前程式結束後靜默安裝至 `%LocalAppData%\SnipFlow`，再啟動新版。安裝目錄仍有其他執行中的程式、截圖資料夾位於該目錄或下載驗證失敗時會停止更新並保留現有檔案。開發預覽 host 不提供套用更新。

更新前會把原圖與可編輯標註保存到 `%LocalAppData%\SnipFlowData\UpdateSessions`，重新啟動後恢復目前圖片、文字、箭頭、框線等物件；更新前的復原／重做紀錄不保留。即使關閉 PNG 自動儲存，也會先完成此工作保存；保存失敗時不會開始套用更新。工作保存檔留在本機，無法恢復時可從該資料夾找回原圖。

0.4.0 採中性石墨灰、柔白文字與細邊框，搭配使用者選定的「Flow S」Logo。設定分為「一般／快捷鍵／更新」；主視窗、錄影操作條、OCR 與程式提示視窗使用相同色系。

0.5.3 統一使用內嵌的多尺寸 ICO 作為視窗圖示。主視窗顯示、工作列按鈕重建或 DPI 改變時會重新套用圖示；首次顯示也會通知 Windows 更新 SnipFlow 自己的程式檔與圖示項目，改善工作列保留預設圖示的情況。

0.6.0 為主視窗設定與 SnipFlow 自有安裝捷徑一致的工作列身分、重新開啟命令及 Logo 來源。安裝捷徑的程式和圖示路徑會解析為實際檔案位置；只修正經過本安裝路徑與預設身分檢查的 SnipFlow 捷徑，保留自訂捷徑設定。圖示來源的設定失敗會記錄原因，保留原有 WPF 圖示處理。

設定、最多 80 張截圖歷史與錯誤紀錄放在 `%LocalAppData%\SnipFlowData`，與會被更新取代的程式目錄分開。停用歷史只會停止記錄新的截圖。截圖、OCR 內容與紀錄都不會由發布腳本上傳。

預覽版尚未使用程式碼簽章；正式公開散布前應配置受信任的 Windows 簽章憑證。Velopack 檢查更新套件雜湊；首次自動安裝另核對 GitHub Release 資產的 SHA-256，更新來源固定為本專案的 HTTPS GitHub URL。

## 開發

需要 Windows 10 2004+ / Windows 11，以及 .NET 10 SDK。

```powershell
dotnet build src/SnipFlow.csproj -c Release
dotnet run --project src/SnipFlow.csproj
```

`build-release.ps1` 建立自含執行環境的 Windows x64 發布目錄與 Velopack 安裝包。它只打包本專案程式檔案，不打包使用者資料。`-Version` 決定應用程式與套件版本。產物在 `release/`；發布到 GitHub 後，已安裝的舊版才能取得更新。

```powershell
./build-release.ps1 -Version 0.6.3
```
